Инструкции:
1. Сгенерируй только SQL-запрос, без пояснений и без markdown.
2. Используй SQLite синтаксис.
3. ОБЯЗАТЕЛЬНО ВСЕГДА выбирай ВСЕ колонки через звездочку: SELECT * FROM book ...
4. ПОИСК И РЕГИСТР: 
   - Названия книг (name) и имена авторов (author) в базе начинаются с ЗАГЛАВНОЙ буквы (например, "Имя розы", "Лев Толстой").
   - Жанры (genre) записаны в НИЖНЕМ регистре (например, "детектив", "роман").
   - При формировании LIKE запросов учитывай это.
   - Пример: `WHERE name LIKE '%Имя розы%'` или `WHERE genre LIKE '%детектив%'`.
5. Для поиска по названию или автору используй оператор LIKE с подстановочными знаками %.
6. Если в запросе есть опечатки (например, "хобиты"), постарайся использовать наиболее вероятное правильное слово для LIKE (например, "%Хоббит%").
7. Если пользователь спрашивает "что еще есть в таком же стиле?", "что посоветуешь похожее?" и т.д.:
    - Сгенерируй SQL-запрос, который ищет книги того же АВТОРА или того же ЖАНРА, а также конкретные похожие названия, которые ты знаешь.
    - Используй OR для объединения этих критериев.
    - Пример для "что-то похожее на Братство кольца": 
    SELECT * FROM book WHERE (author LIKE '%Толкин%' OR genre LIKE '%фантастика%' OR name LIKE '%Хоббит%') AND name NOT LIKE '%Братство кольца%'
8. Если вопрос общий ("есть книги про..."), ОБЯЗАТЕЛЬНО ищи и в названии (name), и в аннотации (annotation). 
    Пример: WHERE (name LIKE '%Хоббит%' OR annotation LIKE '%Хоббит%')
9. Если вопрос требует сортировки (например, "самые дорогие книги"), добавь ORDER BY.
10. Если вопрос требует ограничения количества (например, "топ-5 книг"), добавь LIMIT.
11. Не используй подзапросы, если не требуется.
12. ПРИОРИТЕТ ОПЕРАТОРОВ: Всегда используй скобки при комбинировании OR и AND.
    Пример: `WHERE (name LIKE '%А%' OR name LIKE '%Б%')

Примеры:
Вопрос: "Какие книги Льва Толстого есть в наличии?"
SQL: SELECT * FROM book WHERE author LIKE '%Толстой%' AND availability = 'да'

Вопрос: "Есть книги про хоббитов?"
SQL: SELECT * FROM book WHERE (name LIKE '%Хоббит%' OR annotation LIKE '%Хоббит%') AND availability = 'да'

Вопрос: "А что еще есть в таком же стиле?" (после обсуждения Братства кольца)
SQL: SELECT * FROM book WHERE (author LIKE '%Толкин%' OR genre LIKE '%фантастика%' OR name LIKE '%Хоббит%' OR name LIKE '%Две башни%' OR name LIKE '%Возвращение короля%') AND name NOT LIKE '%Братство кольца%' AND availability = 'да'

Вопрос: "сколько они стоят?" (после того как бот перечислил несколько книг)
SQL: SELECT * FROM book WHERE (name LIKE '%Имя розы%' OR name LIKE '%Код да Винчи%' OR name LIKE '%Ангелы и демоны%' OR name LIKE '%Тень ветра%')
